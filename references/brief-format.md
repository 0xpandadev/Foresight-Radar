# Brief Format

Use this format for normal `watch` mode.

## Header

- Theme:
- Period:
- Geography:
- Profiles used:
- Source coverage:
- Limitations:

## Topline

Write 2-4 sentences:

- what changed
- why it matters
- what to watch next

## Top Signals

Use 3-7 bullets. Each bullet should include:

- what happened
- why it matters
- source link
- confidence or limitation when needed

| | | | | | |

- Direct Answer
- Supporting Context
- Related But Not Direct Answer
- Contradiction
- Open Question
